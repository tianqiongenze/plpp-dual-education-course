# 《千人千面 AI 学习平台项目实战》课程教学方案(总纲)

> 本方案规定本课程的**教学方法论骨架**:双元制六步法 + 费曼学习法 + 布鲁姆目标链。三法咬合,贯穿 16 次课。

## 1. 设计哲学:一个真实项目,三种方法咬合

```
        双元制(组织骨架)          费曼(检验机制)         布鲁姆(目标阶梯)
     ┌──────────────────┐    ┌──────────────┐    ┌─────────────────┐
     │ 六步法节律:       │    │ 每课 15min    │    │ 目标动词分层:    │
     │ 资讯→计划→决策→   │───▶│ 学生上讲台,   │───▶│ 记/解 → 应 →     │
     │ 实施→检查→评价    │    │ 讲不清楚=没学会│    │ 析 → 评/创       │
     └──────────────────┘    └──────────────┘    └─────────────────┘
                    全部落在 PLPP 真实工程的 16 个学习情境上
```

- **双元制解决"在哪学、跟谁学"**:学校元(教师+实训室)+企业元(真实工程+工程师时间)。
- **费曼解决"学会没有"**:学生能用自己的话讲给同伴听、讲给教师听,讲不清即返工——这是唯一诚实的检验。
- **布鲁姆解决"学到多深"**:每课目标显式标注认知层级,考核按层级加权,防止课堂停留于记忆层。

## 2. 双元制本土化要点(与德国原型的差异与理由)

| 德国原型 | 本土化改造 | 理由 |
|---|---|---|
| 企业实训 3.5 天/周 | 每周 1 次"工程师时间"+真实工程载体 | 高职在校课时约束;以"真实项目替代企业现场" |
| 学徒合同 | 课程学徒制(分组+工单制) | 无劳动契约,以任务单契约替代 |
| Meister 师傅制 | 双导师(教师+企业/项目工程师) | 工程视角评价纳入 25% 过程分 |
| 学习领域课程 | 8 个 LF × 学习情境 | 保留原模式组织方式 |

**工程纪律作为素养目标内嵌**(源自项目铁律,本土化为"学徒守则"):
1. 诚实优先:落盘以可核验事实为准,事故如实记根因,不掩饰;
2. 操作分级:L0 只读直接做 / L1 可逆授权做 / L2 不可逆先确认+备份 / L3 灾难性必须教师授权;
3. 编译过 ≠ 正确:必须运行+验证一次真实执行路径;
4. 无产物不声称完成:每项作业必须附命令输出或截图证据。

## 3. 费曼学习法实施规程(每课 G 环节 15min + 课后)

### 3.1 课堂费曼四步(15 分钟)
1. **选定讲题**(2min):本课核心概念,如"为什么 Outbox 能防丢事件?"
2. **白纸讲授**(6min):学生 A 上台,不看笔记,用自己的话+画图讲给全班;同伴扮演"12 岁学生"追问"我没听懂"
3. **卡壳回炉**(4min):卡壳处即是知识漏洞——当场翻资料回炉,重讲该段
4. **类比压缩**(3min):用一个生活类比+一句话总结收束(教师只提问不代讲)

### 3.2 课后费曼卡(每课作业之一)
- 每人交一张"费曼卡":正面=概念讲给外行听的 200 字;背面=一个类比图。
- 评分标准(纳入过程分):外行能懂(40%)、类比喻体准确(30%)、暴露并修复了一个误解(30%)。

### 3.3 费曼与双元制的咬合点
实施环节(E)中教师巡回时**只提问不代写**,逼出学生口头复述;检查环节(F)互查者必须向被查者提一个"为什么"。

## 4. 布鲁姆目标链实施规程

1. **备课层**:每次课目标 3-5 条,动词必须落在不同层级,且至少 1 条【析】以上(见授课计划)。
2. **课堂层**:理论精讲(D)按"记忆层→理解层→应用层"爬梯,每爬一层抛一个提问(点名+追问依据)。
3. **实训层**:任务单的检查清单按层级分组——【应】类条目"能做出来",【析】类条目"能说清为什么"。
4. **考核层**:费曼答辩抽【析/评】层题目;理论测验只考【记/解】层;里程碑评分矩阵按层级加权。

### 布鲁姆动词速查(学生版,贴在任务单首页)
- 记忆:说出/列出/指认
- 理解:解释/对比/举例说明
- 应用:配置/运行/实现/演示
- 分析:剖析/诊断/对比权衡/找根因
- 评价:评审/拷问/判定优劣
- 创造:设计/重构/再开发

## 5. 教学组织与场地

- 分组:4 人/组(学徒组),组内角色每周轮换:**工单员**(领任务单)、**操作员**(上机)、**检查员**(对照清单)、**费曼员**(代表讲课)。
- 场地:理实一体化教室(前后分区:理论区/实训区)+ 云端教学集群(每组独立 namespace 或教学租户)。
- 安全红线(每次课决策环节重申):教学集群内禁止对 10.167.2.x 生产网段执行 L2/L3 操作;所有 DROP/DELETE/reset 前必须教师签字。

## 6. 与 PLPP 项目的对接纪律

- 学生一律在**自己的分支**开发,禁止直接推 master;
- 项目更新(修复/事故/数据变化)由同步脚本拉入课程仓 `project-references/`,教师课前 10 分钟据此刷新情境;
- 每次课的"情境导入"素材必须取自项目真实近况(PROGRESS 最新阶段),保证"教学跟着工程走"。
