## 知识建构精讲要点(理论 35min,教师主持)

### 智能体四工具
- edu_tools:检索/RAG、query_knowledge_graph、掌握度、学习路径
- 工具=LLM 的'手':先选工具再执行再汇总
### 行为事件链(端到端)
- agent behavior.py:学生行为→publish_learning_behavior(fail-soft)
- Pulsar topic(platform/edu 主题族)→teaching LearningBehaviorListener(teaching-mastery-sub)
- →POST kt /kt/events→KT 计数(l1EventCount)递增——真实验证值 l1=2
### fail-soft 设计
- 生产者发送失败:记日志+走降级,绝不抛异常打断主学习流程
- 对照:fire-and-forget 的三种坏(sendAsync 悬空/队列满静默丢/失败仅 warn)——LF7 深挖

## 实训实施(70min,双师巡回)

1. **1. 读生产者** — agent behavior.py:定位 topic 名与 fail-soft 分支
2. **2. 发事件** — 触发/手工发布一条学习行为事件
3. **3. 验证下游** — 查 KT l1EventCount 前后对比(应+1)
4. **4. 排查演练** — 教师注入一处断点(改 topic 名),小组用逐跳法定位

## 费曼讲台(15min)
**讲题:用'快递链:商家发货(producer)→物流(topic)→驿站(listener)→签收(KT)'讲事件链,并说明哪一环最容易'丢件'。**
规程:白纸讲授 6min(不看笔记)→同伴追问 4min(卡壳即回炉)→类比压缩 3min。未过检查清单的小组不得上台。
