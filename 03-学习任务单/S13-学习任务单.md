## 知识建构精讲要点(理论 35min,教师主持)

### 学习路径状态机
- IN_PROGRESS/COMPLETED 等状态;step 粒度推进;教学域 learning_paths 表
- 路径=个性化推荐的执行载体(KT 输出驱动)
### SRS 与 SM-2
- 间隔重复:记住后拉长复习间隔;SM-2 按质量评分调 EF/间隔
- 复习记录=读-改-写:读旧间隔→算新间隔→写回——并发下会互相覆盖
### OCC 乐观锁(真实修复)
- 加 version 列:UPDATE ... WHERE id=? AND version=旧版本
- 0 行受影响=冲突→重读重算重试(退避,上限转 409)
- 基线读必须走主库强读,禁 follower 旧值

## 实训实施(70min,双师巡回)

1. **1. 复现** — 双线程并发调用同 (user,word) 复习接口,统计间隔丢失次数
2. **2. 读修复** — 对照 teaching SRS 的 version 实现逐行讲解
3. **3. 验证** — 同样并发下验证 version 冲突重试生效(丢失=0)
4. **4. 用例** — 写一个'冲突→重试→成功'的测试用例(组内 PR)
