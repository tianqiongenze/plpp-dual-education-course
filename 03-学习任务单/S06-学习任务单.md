## 知识建构精讲要点(理论 35min,教师主持)

### TiDB 三组件
- TiDB Server(无状态 SQL 层,MySQL 协议)/ TiKV(行存 KV)/ PD(调度+TSO)
- 扩容=加节点,数据自动再平衡——对比单机 MySQL 的天花板
### PLPP 数据拓扑
- 五库:course_db/teaching_db/iam_db/tenant_db/agent_db(+ai_db)
- 规模感:knowledge_points 4570 万行 / resources 3828 万 / discussions 1198 万
- TiDB NodePort 30210(MySQL 协议);CRDB 30257(PG 协议)
### 为什么双存储
- TiDB=主库(统一数据层);CRDB=备份侧(随时切换的能力)
- 切换的前提=持续同步——下一课的主题

## 实训实施(70min,双师巡回)

1. **1. 连库** — mysql 客户端/pymysql 连 10.167.2.175:30210
