## 5. 理论精讲提纲(35min)

### 1) LLM 服务链
- 应用层(agent/ai)→LLM 网关(litellm,多供应商路由)→推理(ollama qwen2.5:14b)
- 配置在 configmap-secret.yaml:LLM_BASE_URL/LLM_MODEL
### 2) fallback 与降级
- config.build_llm(with_fallbacks):主模型挂→备用模型顶上
- 韧性视角:LLM 也是'外部依赖',同样要超时/重试/降级
### 3) 真实事故:litellm DB
- DATABASE_URL 注入→Prisma CLI 工具链 600s 超时→CrashLoop→回滚
- 决策依据:主链不依赖 litellm(直连 ollama)→先绕行,基座问题挂账
- 诚实挂起≠放弃:记录根因+后续方案(pre-migration Job/官方镜像)
### 4) 成本意识(LCO 三层缓存)
- L1 精确缓存/L2 语义缓存/L3 知识图谱——省 40%+ 成本
- 缓存命中必须透传元数据(cache_hit/cache_layer)供监控

## 6. 实训指导(70min)

1. **1. 看配置**:读 configmap-secret.yaml 的 LLM_* 三键,画通道图
2. **2. 切通道**:(教学租户)LLM_BASE_URL 指向 ollama-worker,重启 agent pod
3. **3. 跑对话**:经 agent 助手发起一次问答,确认响应与模型名
4. **4. 复盘卡**:litellm 事故卡:现象/根因/决策/挂账方案四栏

## 8. 费曼讲题与引导
讲题:给外行讲'大模型网关'像'旅行社':你只说要去哪,它帮你选航班,航班取消还能改签(fallback)。
追问链:还有吗?→换个说法?→如果外行问…你怎么答?→一句话压缩?
